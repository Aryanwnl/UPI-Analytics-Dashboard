# 📊 Digital Payments: UPI Trends & Insights  
### UPI Transaction Analytics Dashboard – 2024  
**Author: Aryan Dalvi**

---

## 🌐 Project Overview
This project presents an interactive **Power BI dashboard** analyzing key trends in **UPI (Unified Payments Interface)** transactions across the year **2024**.

The report highlights patterns across:
- 📅 Monthly Transaction Trends  
- 👥 Age Groups  
- 🛍️ Merchant Categories  
- 💳 Payment Methods  
- 🎯 Transaction Purpose  
- 🔁 Transaction Types  
- 💰 Amount & Balance Visual Analytics  

This dashboard helps uncover behavioural insights in India’s digital payments ecosystem.

## 🧠 Key Insights
- 📈 Peaks in activity during **February, May, and October**  
- 📉 Highest dip in **March and August**  
- 👨‍👩‍👧 Middle-age consumers show the highest UPI usage  
- 🛍️ Certain merchant types dominate repeat transactions  
- 💳 UPI supports both micro-payments and high-value transfers  
- 🔁 Balance trends reveal spending and savings cycles  

---

## 🚀 How to Use the Dashboard
1. Download the file: **`Upi_Tranaction_Report.pbit`**  
2. Open it using **Power BI Desktop**  
3. When prompted, choose the dataset: **`UPI Transactions.xlsx`**  
4. Click **Refresh** to load visuals  
5. Explore the interactive dashboard filters and insights
